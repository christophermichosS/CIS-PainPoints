# CIS Process Review Workbooks

Two standalone, browser-based workbooks for reviewing a process, capturing pain points, and planning lead-time improvements. No server, database or install is required. Everything runs in the browser.

## Contents
| File | Purpose |
|---|---|
| index.html | Part 1: process map and pain-point capture (Participant and Facilitator modes) |
| CIS_Improvement_Prioritization_Workspace.html | Part 2: lead-time reduction planning and prioritization |

## Part 1 - Process Review Workbook (index.html)
- Interactive process map with zoom, fit-to-width/height, mini-map, search and step-by-step walk-through.
- Filter by team, highlight handoffs, heat map of hotspots, trace upstream/downstream.
- Participants log pain points per step (category, severity, impact, cause, improvement idea, time lost, frequency) and submit a JSON workbook file.
- Facilitators import many participant workbooks, review a consolidated register, view insights, and export CSV.
- Presenter mode and dark theme.

## Part 2 - Improvement Prioritization Workspace
- Guided steps from pain points to countermeasures, prioritization and action planning.
- Tracks post-arrival possible saving, pre-arrival slack and missing time estimates.
- Import a Part 1 workbook, export your work, print-friendly view, dark theme.

## How to use
1. Open the file in a modern browser (Chrome, Edge, Firefox), either from the hosted site or by downloading it.
2. Participants: add pain points on the map, then Workbook > Submit workbook. Send the downloaded JSON file to the facilitator.
3. Facilitator: switch to Facilitator mode, import all participant files, review the register, then continue to Part 2.

## Data and privacy
- No data is sent anywhere by the pages. Work is saved in your browser and in files you download.
- Do not enter sensitive or personal information beyond what the exercise requires.
- Use the Clear buttons on shared computers.
